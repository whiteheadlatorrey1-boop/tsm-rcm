🚀 Quick-Start Checklist

  1. Start the Loop: Ensure the global header clock is running. If paused, click Start Simulation.
  2. Deploy a Fault: Go to the Scenario Injector panel on the right and click Deploy on any scenario. Watch the Real-Time Core Log capture the failure.
  3. Fix the System: Open the operations consoles below to monitor and resolve issues.

🛠️ Console Layout Breakdown

  • NOC Command Center: Best for monitoring physical hardware metrics, network topology, and triggering server reboots.
  • L1 Ticket Copilot: Houses user tickets, timeline diagnostics, and AI resolutions. Run process checks and restart services here.
  • Service Desk Wall: High-visibility whiteboard tracking SLA countdowns—perfect for multi-monitor setups.
  • Gamified Mission Queue: Complete objectives and earn XP to level up your user profile!

💡 Troubleshooting Tips

Clocks out of sync? Use the Reset System button in the header. It clears out all cached states in localStorage and reboots the main bus loop.
