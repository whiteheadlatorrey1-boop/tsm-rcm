# TSM-Consultz — One-Pager Template

Single-vertical format, meant to be printed or emailed as a standalone PDF. Build one per industry using this structure. Image paths reference `./media/` from the generated media kit.

---

## Layout (top to bottom)

**Header**
- Logo + "[Industry] Solutions" (e.g. "Healthcare Solutions")
- One-sentence value proposition

**Hero visual**
- Primary screenshot showing the War Room interface with visible AI recommendations, mission queue, and KPI cards in view
- Example (Healthcare): `media/healthcare/war-room.png`
- Full-page captures work best here if the top-of-page content is representative — otherwise crop to the most information-dense section

**Three-column "what you get" section**
1. AI Recommendations — brief description + small crop from `media/[vertical]/strategist.png`
2. Mission Queue — brief description
3. Executive Reporting — brief description + small crop from `media/[vertical]/executive-dashboard.png`

**Footer**
- CTA (demo request, contact info)
- Website/contact details
